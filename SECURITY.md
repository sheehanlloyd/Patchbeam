# Security Policy

## Reporting a vulnerability
Please report security issues **privately** using GitHub's [private vulnerability reporting](https://github.com/sheehanlloyd/Patchbeam/security/advisories/new) for this repository. Don't open a public issue. Include steps to reproduce, the affected version (About tab or `CFBundleShortVersionString`), and your macOS version.

## Supported versions
Only the latest `main` and the most recent preview release receive fixes.

## Scope notes
Patchbeam's security model, including what it does **not** protect against (a Git worktree isn't a sandbox), is documented in [docs/SECURITY.md](docs/SECURITY.md).
